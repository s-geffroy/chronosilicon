## Qualité des contributions

- `npm run contribute:check` (strict) refuse : extrait absent, localisateur vide de sens, URL sans hôte, unité incompatible avec la grandeur, mesure sans protocole, calcul incomplet, source inconnue, valeur illustrative (tests unitaires).
- Les extractions existantes sont rejouées par `validate:data`. Celles de M00 sont contrôlées en mode non strict : leurs protocoles sont dans `decisions.json`.
- La curation refuse tout fichier inconnu dans `data/raw/`. Une valeur sans verdict indépendant reste `pending` et n'est pas publiée.
- Les valeurs écartées sont publiées avec leur motif (Laboratoire).
- Fournis : modèle d'issue, CONTRIBUTING.
- Limite : rien n'atteste techniquement que le vérificateur est une autre personne que l'extracteur. La revue humaine des PR reste requise (CS-12).
