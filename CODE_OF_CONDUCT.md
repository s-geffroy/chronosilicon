# Code de conduite (proposé)

CHRONOSILICON veut rester un espace de travail respectueux, ouvert et factuel.

- Critiquez les données, les arguments et le code, jamais les personnes.
- Les désaccords scientifiques se règlent par des sources et des mesures documentées.
- Harcèlement, propos discriminatoires, attaques personnelles et divulgation d'informations privées sont exclus.
- Le mainteneur peut modérer, masquer ou refuser une contribution qui enfreint ces règles.

Signalement : ouvrez une issue privée de sécurité sur le dépôt GitHub, ou contactez le mainteneur via son profil GitHub. Ce texte est provisoire (CS-12) et sous CC BY 4.0.
